================================================================================
TROUBLESHOOTING
================================================================================

Q: What if the auto-fix breaks something?
A: You have backups! Just restore:
   cp portfolio_manager.py.backup_20260226_143022 portfolio_manager.py

Q: What if I don't want backups?
A: They're harmless - just delete them:
   rm *.backup_*

Q: Will it modify my database?
A: No! Only code files are modified. Database stays untouched.

Q: Can I undo changes?
A: Yes! Use the backup files (saved automatically).

Q: What if I want to see what would be fixed first?
A: Run with --no-fix flag:
   python test_portfolio_integrity_autofix.py --no-fix
